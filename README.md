
# MyBank - Simple Banking Application

## Project Overview

MyBank is a simple frontend banking application
developed using HTML, CSS and JavaScript.

It demonstrates basic banking operations.

## Features

- Display account holder information
- View available account balance
- Deposit money
- Withdraw money
- Validate withdrawal amount
- Display transaction history

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)

## Project Structure

git-demo/
|

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run index.html using a local development server.
4. Test the deposit and withdrawal operations.

Note: This is a frontend demonstration project.
It does not connect to a real bank or database.
It does not implement authentication or secure
financial transactions.
